App bekerja penuh tanpa internet. Sheet dan Drive dipakai sebagai salinan supaya bisa dibuka dari perangkat lain.

Google Sheet & Drive

OCR memakai layanan Drive. Sekali saja: di editor Apps Script buka Services, tambahkan Drive API, lalu deploy versi baru.
Perlu menyala kalau kamu mau melihat gambarnya dari HP atau laptop lain. Kalau dimatikan, Drive hanya jadi cadangan dan gambar cuma tampil di perangkat tempat kamu mengunggahnya.
Belum punya alamatnya? Buka langkahnya
1. Buka Google Sheet baru.
2. Menu Extensions → Apps Script, hapus isinya, tempel seluruh isi file Code.gs.
3. Ganti baris TOKEN dengan kode rahasia karanganmu, lalu simpan.
4. Deploy → New deployment → Web app. Execute as Me, Who has access Anyone.
5. Salin URL yang berakhiran /exec ke kolom di atas, tulis token yang sama.
6. Tekan Uji sambungan. Folder Drive dibuat sendiri begitu sambungan pertama berhasil.

Kecepatan Ukuran

Impor script dari Markdown

Menerima .md, .tsv, dan .json — bentuknya dikenali sendiri. Bisa beberapa file sekaligus, atau tempel isinya. Bentuk Markdown-nya bebas — pola judulnya dipelajari dari isi filemu sendiri. Satu script dianggap berakhir saat judul script berikutnya muncul, jadi garis --- di tengah naskah tidak memotong isinya. Judul yang tidak menyebut nomor tetap masuk dengan nomor lanjutan.

Kosongkan kolom seri kalau tiap file punya seri sendiri. Kalau diisi, semua script yang masuk pakai seri itu.
Pilih tab tujuan untuk script yang diimpor. Tambah tab baru di halaman Script.
